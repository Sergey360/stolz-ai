# Штольц А.И.

Ни одного лишнего токена.

STOLZ A.I. v0.9.0 — независимый набор из пяти навыков для экономной и
проверяемой работы агентов программирования. Установка добавляет навыки,
профили и ленивые адаптеры, но не запускает фоновую службу, общий кеш или
автоматический контроллер ожидания.

Для Codex доступен один явный локальный API: `stolz-ai/codex-local-state`.
Его вызывают только с `enabled: true` и абсолютным путём к рабочей папке. API
связывает ограниченные фрагменты контекста, проверенное повторное
использование и quiet state, но не выполняет сетевые или модельные вызовы.
Неизвестный вход, истёкшая или повреждённая запись, недоступный компонент и
лимит хранилища возвращают обычный проверяемый маршрут. Локальные артефакты
остаются в выбранной рабочей папке; наружу возвращаются только компактные
идентификаторы и метаданные.

Точные свидетельства C2 относятся только к Claude Code 2.1.251 и Qwen Code
0.22.3. Для Codex CLI 0.153.4 проверены четыре локальных запуска, но отдельной
C2-сертификации v0.7 нет. Механизм допуска C3 реализован, однако все текущие
пары провайдеров остаются `withheld`. Эти факты нельзя переносить на другие
версии, модели и провайдеров.

Читайте [основной README](README.md), [установку](docs/installation.md),
[точную матрицу возможностей](docs/architecture.md) и [правила интерпретации
измерений](docs/benchmarking.md). STOLZ не обещает общую экономию токенов без
воспроизводимых сопоставимых данных и одинаковых проверок результата.
