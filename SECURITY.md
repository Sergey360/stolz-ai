# Security

Security fixes target the latest `0.3.x` release and the current `main` branch.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Sergey360/stolz-ai/security/advisories/new). Include the affected revision, reproduction conditions, impact, and a safe mitigation if known. Do not put credentials, private task data, or harmful proof-of-concept details in a public issue.

STOLZ A.I. skills do not require provider credentials. The included foundation represents commands as a program and argument array, validates artifact identities before reuse, and treats missing measurement as unavailable rather than zero.
