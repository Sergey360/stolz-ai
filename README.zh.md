# STOLZ A.I.

不浪费任何 token。

STOLZ A.I. v0.7.1 是一套由五项技能组成的独立工具，用于让编程智能体减少
不必要的工作并保留可验证性。安装内容包括技能、配置文件和惰性适配器；它不会
启动后台服务、共享缓存、持久状态存储或自动轮询控制器。

C2 证据仅适用于 Claude Code 2.1.251 和 Qwen Code 0.22.3。Codex CLI
0.153.4 已完成四次本地安装运行，但 Codex 没有 v0.7 C2 记录。C3 成对准入按
fail-closed 方式实现，目前所有提供商组合仍为 `withheld`。这些结论不能自动扩展
到其他版本、模型配置或提供商。

请阅读[英文 README](README.md)、[安装说明](docs/installation.md)、
[精确能力矩阵](docs/architecture.md)和[基准解释](docs/benchmarking.md)。没有
可复现且可比较的证据时，STOLZ 不作普遍节省 token 的声明。
