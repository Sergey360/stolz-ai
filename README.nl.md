# STOLZ A.I.

Geen token verspild.

STOLZ A.I. v0.7.1 is een onafhankelijke set van vijf vaardigheden voor zuinig
en verifieerbaar werk door programmeeragenten. De installatie voegt
vaardigheden, profielen en luie adapters toe; zij start geen daemon, gedeelde
cache, duurzame opslag of automatische pollingcontroller.

C2-bewijs geldt uitsluitend voor Claude Code 2.1.251 en Qwen Code 0.22.3. Vier
lokale uitvoeringen zijn geverifieerd met Codex CLI 0.153.4, maar Codex heeft
geen v0.7 C2-rij. C3-paaradmissie is fail-closed geïmplementeerd en alle huidige
providerparen blijven `withheld`. Deze status geldt niet automatisch voor een
andere versie, modelconfiguratie of provider.

Lees de [Engelse README](README.md), [installatie](docs/installation.md),
[exacte capaciteitenmatrix](docs/architecture.md) en
[benchmarkuitleg](docs/benchmarking.md). STOLZ claimt geen algemene
tokenbesparing zonder reproduceerbaar, vergelijkbaar bewijs.
