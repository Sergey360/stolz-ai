# STOLZ A.I.

אף טוקן לא מתבזבז.

STOLZ A.I. v0.7.1 הוא אוסף עצמאי של חמש מיומנויות לעבודה חסכונית וניתנת
לאימות של סוכני קידוד. ההתקנה מוסיפה מיומנויות, פרופילים ומתאמים שנטענים לפי
צורך; היא אינה מפעילה שירות רקע, מטמון משותף, מאגר מצב מתמשך או בקר סקרים
אוטומטי.

ראיות C2 תקפות רק עבור Claude Code 2.1.251 ו-Qwen Code 0.22.3. ארבע הרצות
מקומיות אומתו עם Codex CLI 0.153.4, אך ל-Codex אין רשומת C2 של v0.7. מנגנון
הקבלה בזוגות של C3 נכשל באופן סגור, וכל זוגות הספקים הנוכחיים נשארים
`withheld`. אין להעביר מצב זה לגרסה, תצורת מודל או ספק אחרים.

ראו את [ה-README באנגלית](README.md), [ההתקנה](docs/installation.md),
[מטריצת היכולות המדויקת](docs/architecture.md) ו[הסבר מדדי
הביצועים](docs/benchmarking.md). STOLZ אינו טוען לחיסכון כללי בטוקנים ללא
ראיות ניתנות לשחזור ולהשוואה.
